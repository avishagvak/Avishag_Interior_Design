# לוגו אבישג - קבצים

הסמל הנבחר: **01 - "המקור, מנוקה"** (הלוגו שאבישג ציירה, בנוי מחדש בקווים נקיים).
כל הטקסטים בקבצים הומרו לקווי מתאר, כך שהקבצים נראים זהה בכל מחשב גם בלי הגופנים מותקנים.

| קובץ | מה זה | מתי להשתמש |
|-|-|-|
| `avishag-mark-*` | הסמל לבד | אייקון, חותמת, רשתות חברתיות, פינת מסמך |
| `avishag-stacked-he-*` | סמל + "אבישג" + "עיצוב ותכנון פנים" אחד מתחת לשני | כרטיס ביקור, שער של הצעת מחיר, שלט |
| `avishag-stacked-en-*` | סמל + AVISHAG + INTERIOR DESIGN | חומרים באנגלית |
| `avishag-horizontal-he-*` | סמל מימין, שם משמאל | כותרת אתר, חתימת מייל, נייר מכתבים |
| `avishag-horizontal-en-*` | סמל משמאל, שם מימין | כנ"ל, באנגלית |

צבעים: `ink` = כמעט שחור (#2b2a27) לרקע בהיר, `white` = לבן לרקע כהה או לתמונה, `sage` = ירוק מרווה (#5e6b52).
פורמטים: `.svg` (וקטורי, לכל גודל, לאתר ולדפוס) ו-`.png` (רקע שקוף, 2000 פיקסל רוחב, לוורד/קנבה/וואטסאפ).

גופנים בשם: Rubik Light (השם), Assistant (שורת המשנה).
אייקונים לאפליקציה ולדפדפן נמצאים ב-`assets/icons/`.
